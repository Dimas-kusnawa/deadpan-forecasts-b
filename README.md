# Deadpan Forecasts for Cities That Do Not Exist

Competition slug: u-coral-ibis-18-deadpan-forecasts-for-cities-that-do-151d4d8c

A single deadpan weather forecast for Brindlewick, a city that does not exist.

Run `python3 main.py` and it writes one line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`).
